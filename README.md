## Description

Project backend menggunakan NestJS dan TypeScript.

## Project setup

```bash
npm install
```

## Compile and run the project

```bash
# development
npm run start

# watch mode
npm run start:dev

# production mode
npm run start:prod
```

## Run tests

```bash
npm run test
npm run test:e2e
npm run test:cov
```
